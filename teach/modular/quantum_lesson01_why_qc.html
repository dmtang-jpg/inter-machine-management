量子比特的数学表示 / Mathematical Representation of Qubits

在量子力学中，量子比特的状态用狄拉克符号（Dirac notation）表示：

基态表示 / Basis States

|0⟩ = $\begin{pmatrix} 1 \\ 0 \end{pmatrix}$,　 |1⟩ = $\begin{pmatrix} 0 \\ 1 \end{pmatrix}$

|0⟩ 和 |1⟩ 是二维复向量空间 ℂ² 的一组正交归一基。

一般量子态 / General Quantum State

|ψ⟩ = α|0⟩ + β|1⟩ = $\begin{pmatrix} \alpha \\ \beta \end{pmatrix}$,　 |α|² + |β|² = 1

α, β ∈ ℂ 是复数概率幅（probability amplitudes）。测量时得到 |0⟩ 的概率为 |α|²，得到 |1⟩ 的概率为 |β|²。

经典比特 Classical bit
0 或 or 1
→
量子比特 Qubit
α|0⟩+β|1⟩

布洛赫球 / The Bloch Sphere

单量子比特的纯态可以用布洛赫球面上的一个点参数化：

布洛赫球参数化 / Bloch Sphere Parameterization

|ψ⟩ = cos(θ/2)|0⟩ + eiφ sin(θ/2)|1⟩,　 0 ≤ θ ≤ π, 0 ≤ φ < 2π

θ 是极角（与z轴夹角），φ 是方位角（在xy平面内与x轴夹角）

北极 North pole
|0⟩ (θ=0)
南极 South pole
|1⟩ (θ=π)

张量积与多量子比特 / Tensor Product & Multi-qubit States

多个量子比特的复合系统用张量积（⊗）构造：

张量积定义 / Tensor Product Definition

|a⟩ ⊗ |b⟩ = |ab⟩ (简写 / shorthand)

若 |ψ⟩ = α|0⟩ + β|1⟩，|φ⟩ = γ|0⟩ + δ|1⟩，则：

|ψ⟩ ⊗ |φ⟩ = αγ|00⟩ + αδ|01⟩ + βγ|10⟩ + βδ|11⟩

n 量子比特的 Hilbert 空间 / n-qubit Hilbert Space

(ℂ²)⊗n ≅ ℂ2ⁿ

n 个量子比特的状态空间维度为 2ⁿ。3 个量子比特的基态：

|000⟩ |001⟩ |010⟩ |011⟩ |100⟩ |101⟩ |110⟩ |111⟩

关键洞察：n 个量子比特可以同时处于 2ⁿ 个基态的叠加！

常见误解 / Common Misconceptions

误解 1："快一万倍"

量子加速只在特定问题上有效

对排序、网页浏览等无加速

误解 2："会破解所有密码"

理论上可破解RSA/ECC

但需要数百万量子比特，当前只有约1000

误解 3："取代经典计算机"

量子计算机是协处理器

类似GPU，非独立电脑

误解 4："量子并行=同时算所有答案"

叠加态包含所有可能，但测量只给出一个结果

需要精心设计的量子算法让正确答案概率增强

概率诠释 / Born Rule

P(|0⟩) = |α|² = |⟨0|ψ⟩|²,　 P(|1⟩) = |β|² = |⟨1|ψ⟩|²

⟨0|ψ⟩ 是内积（inner product），表示 |ψ⟩ 在 |0⟩ 方向上的投影。

量子比特：同时是 |0⟩ 和 |1⟩（概率幅叠加）/ Simultaneously |0⟩ and |1⟩

与经典概率的区别 / Difference from Classical Probability

经典混合态：50% 概率是0，50% 概率是1（但实际处于其中一个）

量子叠加态：100% 同时是0和1（概率幅可以干涉！）

密码学威胁与应对 / Cryptography Threat & Response

安全威胁

银行交易、数字货币、机密通信都将暴露
