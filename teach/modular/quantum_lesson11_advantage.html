纠缠产生 / Entanglement Generation

SPDC 过程（光子）

|ψ⟩ = ∫ dω_s dω_i f(ω_s, ω_i) â†(ω_s) â†(ω_i) |0⟩

非线性晶体中，泵浦光子（ω_p）→ 信号光子（ω_s）+ 闲置光子（ω_i）

ω_p = ω_s + ω_i,　 k_p = k_s + k_i

能量守恒 + 动量守恒（相位匹配）→ 纠缠光子对

超导电路耦合

Ĥ_c = ℏg (â†₁â₂ + â₁â†₂)
步骤1：初始态 |ψ(0)⟩ = |+⟩|0⟩ = (|0⟩+|1⟩)/√2 ⊗ |0⟩
步骤2：时间演化 U(t) = exp(-iĤ_c t/ℏ)
步骤3：当 t = π/(4g) 时，|ψ⟩ = (|00⟩ + i|11⟩)/√2

通过控制耦合时间，可以产生任意贝尔态。

交叉谐振（CR）门

Transmon 间通过电容耦合，有效相互作用：Ĥ_eff = ℏg_eff (σ_+^(1)σ_-^(2) + h.c.)

g_eff = g₁g₂(1/Δ₁ + 1/Δ₂)，通过失谐抑制直接能量交换。

CHSH 不等式推导 / CHSH Inequality Derivation

设置

S = E(a,b) − E(a,b') + E(a',b) + E(a',b')

E(a,b) = P(相同) − P(不同)，是测量方向 a 和 b 的关联函数。

隐变量推导（严格）

步骤1：假设存在隐变量 λ ∈ Λ，概率分布 ρ(λ)
步骤2：测量结果 A(a,λ), B(b,λ) ∈ {+1, −1}
步骤3：E(a,b) = ∫ dλ ρ(λ) A(a,λ) B(b,λ)
步骤4：S(λ) = A(a,λ)[B(b,λ) − B(b',λ)] + A(a',λ)[B(b,λ) + B(b',λ)]
步骤5：由于 B(b,λ) ∈ {±1}，[B(b,λ) − B(b',λ)] 和 [B(b,λ) + B(b',λ)] 中一个为 ±2，另一个为 0
|S(λ)| ≤ 2 → |⟨S⟩| = |∫ dλ ρ(λ) S(λ)| ≤ ∫ dλ ρ(λ) |S(λ)| ≤ 2

量子违反

|S_QM| = 2√2 ≈ 2.828 > 2

对于 |Ψ⁻⟩ = (|01⟩ − |10⟩)/√2，选择角度：a=0°, a'=45°, b=22.5°, b'=67.5°

Deutsch-Jozsa 算法 / Deutsch-Jozsa Algorithm

问题定义

给定函数 f: {0,1}ⁿ → {0,1}，承诺 f 要么是常函数（所有输入输出相同），要么是平衡函数（一半输出0，一半输出1）。

经典确定性算法：最坏需要 2ⁿ⁻¹ + 1 次查询。

量子算法：O(1) 次查询！

算法步骤

步骤1：|0⟩⊗ⁿ|1⟩ → H⊗⁽ⁿ⁺¹⁾ → 均匀叠加态
$|ψ_1⟩ = \frac{1}{\sqrt{2^n}} \sum_{x=0}^{2^n-1} |x⟩ \otimes \frac{|0⟩-|1⟩}{\sqrt{2}}$
步骤2：Oracle U_f 作用
$U_f |x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩$
$|ψ_2⟩ = \frac{1}{\sqrt{2^n}} \sum_x (-1)^{f(x)} |x⟩ \otimes \frac{|0⟩-|1⟩}{\sqrt{2}}$
步骤3：再次应用 H⊗ⁿ ⊗ I
$|ψ_3⟩ = H^{⊗n} ⊗ I |ψ_2⟩$
步骤4：测量前 n 个量子比特
$P(|0^{⊗n}⟩) = \left| \frac{1}{2^n} \sum_x (-1)^{f(x)} \right|^2$

证明

常函数：振幅 = ±1 → 概率 = 1
平衡函数：振幅 = 0 → 概率 = 0

一次查询即可区分，经典算法需要指数级查询！

Shor 算法 / Shor's Algorithm

核心思想：周期查找

步骤1：随机选 a < N，计算 gcd(a, N)。若 ≠ 1，找到因子。
步骤2：找 a 模 N 的阶 r：a^r ≡ 1 (mod N)
步骤3：若 r 为偶数，gcd(a^(r/2) ± 1, N) 给出因子。

量子部分：量子相位估计 (QPE)

U|y⟩ = |ay mod N⟩

U 的本征态 |s⟩ 对应本征值 e^(2πi s/r)。通过 QPE 估计 s/r → 得到 r。

QPE 步骤：
$|0⟩|0⟩ → H⊗ᵗ|0⟩|0⟩ → \text{控制-}U^{2^k} → \text{QFT}^† → \text{测量}$

复杂度对比

经典 GNFS：亚指数时间 exp((64/9)^(1/3) (ln N)^(1/3) (ln ln N)^(2/3))

Shor 算法：多项式时间 O((log N)³)

2048位 RSA：经典 ~10¹⁰ 年，量子 ~100 天（假设 10⁶ 门/秒）

量子优势来源 / Source of Quantum Advantage

算法加速类型关键资源
Deutsch-Jozsa指数 O(2ⁿ) → O(1)叠加态 + 相位反冲
Grover二次 O(N) → O(√N)振幅放大
Shor指数 → 多项式QFT + 周期查找
量子模拟指数（Hilbert空间）自然量子系统
HHL指数 O(N) → O(log N)相位估计
VQE指数（多体问题）变分原理

三个核心资源

叠加：n 个量子比特同时处于 2ⁿ 个态 → 并行计算
干涉：概率幅的相干叠加 → 增强正确答案，抑制错误答案
纠缠：非经典关联 → 指数级状态空间

关键洞察

量子优势不是免费的：测量只给出一个结果，需要精心设计算法。

量子优势 ≠ 对所有问题都快，只对特定结构问题有加速。
