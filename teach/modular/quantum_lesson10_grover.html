问题设置 / Problem Setup

无序搜索问题

给定 N = 2ⁿ 个元素的数据库，其中恰好有 M 个元素满足某个性质 f(x) = 1。

经典方法：平均需要 N/M 次查询 → O(N/M) 复杂度。

Grover算法：O(√(N/M)) 次查询 → 二次加速！

量子 Oracle

U_w|x⟩ = (-1)^{f(x)} |x⟩ = |x⟩ - 2|x⟩⟨x|w⟩

Oracle 翻转目标态的相位：U_w|w⟩ = -|w⟩，对 |x⟩ ≠ w 无影响。

推导：U_w = I - 2|w⟩⟨w|（关于 |w⟩ 的反射）
$U_w|x⟩ = |x⟩ - 2|w⟩⟨w|x⟩ = |x⟩ - 2\delta_{xw}|w⟩$

初态准备

|s⟩ = H⊗ⁿ|0...0⟩ = $\frac{1}{\sqrt{N}}$ Σ |x⟩

所有基态的均匀叠加 → 初始概率幅 α = 1/√N。

Grover 迭代 / Grover Iteration

一次迭代 = 两步 / Two Steps per Iteration

1. Oracle 反射：U_w = I - 2|w⟩⟨w|（关于 |w⟩ 反射）
2. 扩散算子（关于平均值反射）：U_s = 2|s⟩⟨s| - I

Grover 算子：G = U_s · U_w

几何解释 / Geometric Interpretation

定义两个正交向量：

|w⊥⟩ = (|w⟩ - |s⟩cosθ)/sinθ,　 |s⟩ = sinθ |w⟩ + cosθ |w⊥⟩

其中 sinθ = √(M/N)。每次 G 使状态向量向 |w⟩ 旋转 2θ。

严格证明 / Rigorous Proof

旋转角度推导

G = (2|s⟩⟨s| - I)(I - 2|w⟩⟨w|)

在 {|w⟩, |w⊥⟩} 基下，G 是旋转矩阵：

G = $\begin{pmatrix} \cos 2θ & -\sin 2θ \\ \sin 2θ & \cos 2θ \end{pmatrix}$

k 次迭代后

G^k |s⟩ = sin((2k+1)θ) |w⟩ + cos((2k+1)θ) |w⊥⟩

成功概率：P(k) = sin²((2k+1)θ)

最优迭代次数

(2k+1)θ ≈ π/2 → k_opt = ⌊π/(4θ)⌋ ≈ ⌊π√(N/M)/4⌋

当 N 很大时，θ ≈ √(M/N)，所以 k_opt ≈ π√(N/M)/4。

最大成功率：P_max ≈ 1 - O(M/N)

关键观察

• 超过最优迭代次数后，成功率反而下降！

• 这是量子算法的"过冲"现象。

• 如果不知道 w* 的确切位置，需要随机停止策略。

经典下界 / Classical Lower Bound

Yao 下界定理 (1994)

任何经典随机算法要找到 w*，期望查询次数 ≥ (1-o(1))√(N/M)/2。

Grover 算法是最优的（在常数因子内）！

经典

• 确定性：N/M 次查询

• 随机化：N/(2M) 次查询

量子

• Grover：√(N/M)/4 次查询

• 最优（BBHT 证明）

BBHT 下界 (Bernstein-Vazirani-Høyer-Tappar)

任何量子算法需要 Ω(√(N/M)) 次查询

Grover 算法达到此下界 → 渐近最优。

多目标 Grover / Multi-Target Grover

t 个目标元素

k_opt = ⌊π√(N/t)/4⌋

目标越多，需要的迭代次数越少。

量子计数 (Quantum Counting)

结合量子相位估计，先估计目标数量 t，再运行 Grover。

t ≈ N sin²(θ)

实际应用

Grover 算法是许多量子算法的子程序，如量子计数、量子优化等。

在密码学中，Grover 算法可以将暴力破解密钥的时间从 O(2ⁿ) 降低到 O(2^(n/2))。

1. 算法步骤

• θ ≈ √(M/N)

3. 最优迭代

• k_opt = ⌊π√(N/M)/4⌋

• P_max ≈ 1 - O(M/N)

4. 最优性

• 经典下界 Ω(√(N/M))

• Grover 达到下界
