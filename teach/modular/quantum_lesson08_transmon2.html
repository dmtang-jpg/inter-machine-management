参数优化 / Parameter Optimization

Transmon 频率公式推导

从 Cooper pair box 哈密顿量出发：

Ĥ = 4E_C (n̂ - n_g)² - E_J cos(φ̂)

在电荷基下展开，保留最低两个能级（|0⟩ 和 |1⟩），做二阶泰勒展开：

步骤1：cos(φ) ≈ 1 - φ²/2 → Ĥ ≈ 4E_C(n̂ - n_g)² + E_J φ̂²/2
步骤2：引入升降算符 â = (φ̂ + in̂)/√(2ζ)，其中 ζ = √(8E_J/E_C)
步骤3：Ĥ ≈ ℏω₁₀(â†â + 1/2) + α(â†â)²â²/2
ω₁₀ = (√(8E_J E_C) - E_C)/ℏ,　 α = -E_C/ℏ

设计权衡 / Design Trade-off

E_J/E_C 越大 → 电荷噪声抑制越好（Δχ ∝ exp(-√(8E_J/E_C))），但非谐性越小

非谐性 |α| 必须远大于门操作速率（~10 MHz），避免泄漏到 |2⟩ 态

最优 E_J/E_C ~ 50-80：电荷噪声 ~100 kHz，非谐性 ~200-350 MHz

色散读出推导 / Dispersive Readout Derivation

Jaynes-Cummings 相互作用

Ĥ_int = ℏg (â†σ_- + âσ_+)

g 是耦合强度，â 是腔模算符，σ_± 是 Transmon 升降算符。

Schrieffer-Wolff 变换

在色散极限 |Δ| = |ω₁₀ - ω_c| ≫ g 下，做微扰展开：

步骤1：总哈密顿量 Ĥ = ℏω_c â†â + ℏω₁₀ σ_z/2 + Ĥ_int
步骤2：引入变换 Î = exp[S]，其中 S = (g/Δ)(â†σ_- - âσ_+)
步骤3：展开到二阶：Ĥ_eff ≈ ℏω_c â†â + ℏω₁₀ σ_z/2 + ℏ(g²/Δ) σ_z â†â
Ĥ_disp = ℏ(ω_c + χσ_z) â†â,　 χ = g²/Δ

χ 是色散移位（dispersive shift），典型值 ~1-5 MHz。

态依赖的腔频率

ω_c(|0⟩) = ω_c - χ,　 ω_c(|1⟩) = ω_c + χ

通过测量反射系数 Γ(ω) 或透射系数 T(ω) 的相位差，判断 Transmon 状态。

读出保真度 / Readout Fidelity

信噪比 (SNR)

SNR = (κ n̄)² / n̄_noise = κ² n̄ / n̄_noise

κ 是腔带宽，n̄ 是平均光子数，n̄_noise 是噪声光子数。

读出保真度推导

设测量时间 τ_m，信号光子数 n̄_sig = κ n̄ τ_m
噪声光子数 n̄_noise = n̄_th τ_m (热噪声)
区分条件：n̄_sig > n̄_noise → κ n̄ > n̄_th
F = 1 - exp(-2κ²(n̄_0 - n̄_1)²τ_m²) / 2

其中 n̄_0 和 n̄_1 是 |0⟩ 和 |1⟩ 对应的平均光子数。

实际性能

现代 Transmon 读出保真度 F > 99%，测量时间 ~100-500 ns。

使用约瑟夫森行波参量放大器（JTWPA），噪声接近量子极限。

T₁ 限制因素 / T₁ Limiting Factors

Purcell 效应

T_Purcell = Q_cavity / (2π × g² × Q_Transmon)

通过读出腔辐射导致的能量弛豫。可通过 Purcell 滤波器抑制。

介电损耗 (TLS)

• 两个能级系统（TLS）在界面处

• Si/SiO₂ 界面密度 ~10¹⁰ cm⁻²

• T₁ ~ 50-200 μs

• 主要限制因素

准粒子隧穿

• 热激发准粒子密度 n_qp

• Γ_qp ∝ √(n_qp)

• 需要 T < 50 mK

• 可通过准粒子陷阱缓解

电荷噪声

• 1/f 噪声谱

• 影响 T₂* (Ramsey)

• 影响 T_echo (回波)

磁通噪声

• 磁通涡旋运动

• 影响 T₁ 和 T₂

• 可通过对称设计抑制

当前记录 (2024)

IBM：T₁ > 1 ms，T₂ > 500 μs（单量子比特）

Quantinuum（离子阱）：T₂ > 10 s

Transmon 改进版本 / Improved Transmon Variants

变体结构特点性能
Xmon (Cross) 十字形电极，电容更大，E_J/E_C ~ 50 T₂ ~ 100 μs，IBM 主力
g-mon 直接耦合两个 Transmon，可调 g 无需总线，耦合强度可调
C-shunt 底部加电容 shunt，减少电压噪声 T₂ 更长，对电荷噪声不敏感
Fluxonium ~1000，电荷噪声极低 T₁ ~ 1 ms，非谐性 ~1 GHz
0-π qubit 拓扑保护，对电荷和磁通噪声都抑制 理论上 T₁, T₂ 都非常长
EFS (Echo) 扩展 Fluxonium，对称设计 对磁通噪声一阶不敏感

Fluxonium 哈密顿量

Ĥ = 4E_C n̂² + E_L (φ̂ - φ_ext)²/2 - E_J cos(φ̂)

E_L 是电感能量，φ_ext 是外磁通。当 E_J/E_C ~ 1000 时，形成周期势阱。

Transmon 设计练习 / Design Exercise

例题：设计一个 Transmon

目标：ω₁₀/2π = 5 GHz，α/2π = -250 MHz

步骤1：由 α = -E_C/ℏ → E_C = 2π × 250 MHz × ℏ = h × 250 MHz
步骤2：由 ω₁₀ = (√(8E_J E_C) - E_C)/ℏ → √(8E_J E_C) = ℏω₁₀ + E_C
步骤3：8E_J E_C = (h×5 GHz + h×250 MHz)² = (h×5.25 GHz)²
步骤4：E_J = (h×5.25 GHz)² / (8 × h×250 MHz) = h × 13.8 GHz
步骤5：E_J/E_C = 13.8 / 0.25 = 55 ✓
步骤6：C_Σ = e²/(2E_C) = (1.6×10⁻¹⁹)² / (2 × h × 250 MHz) ≈ 100 fF
步骤7：I_c = 2π E_J/Φ₀ = 2π × h × 13.8 GHz / (2.07×10⁻¹⁵) ≈ 27 μA

练习：如果目标频率改为 6 GHz，非谐性 -200 MHz，求 E_J/E_C

提示：E_C = h × 200 MHz，√(8E_J E_C) = h(6 GHz + 200 MHz) = h × 6.2 GHz

E_J = (h×6.2 GHz)²/(8×h×200 MHz) = h × 24.0 GHz

E_J/E_C = 24.0/0.2 = 120（更大的 E_J/E_C，更好的电荷噪声抑制）
