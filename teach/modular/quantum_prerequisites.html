1. 复数与欧拉公式 / Complex Numbers & Euler's Formula

量子力学中，波函数和概率幅是复数。理解复数是学习量子计算的第一步。

复数的表示 / Representations

z = a + bi = r eiφ = r(cos φ + i sin φ),　 where i² = -1

r = |z| 是模（magnitude），φ 是辐角（argument）。

复数的共轭：z* = a - bi = r e-iφ

欧拉公式 / Euler's Formula

eiθ = cos θ + i sin θ
cos θ = (eiθ + e-iθ)/2,　 sin θ = (eiθ - e-iθ/(2i)

欧拉公式是连接指数函数和三角函数的桥梁，在量子力学中无处不在。

欧拉公式的物理直觉

eiθ 在复平面上表示一个单位圆上的点。当 θ 连续变化时，点沿单位圆旋转。

这就是为什么量子态中的相位可以看作"旋转"——每个能级的概率幅以不同角频率 e-iEₙt/ℏ 旋转。

全局相位 vs 相对相位 / Global vs Relative Phase

|ψ'⟩ = eiα eiβ|ψ⟩

由于 eiα+iβ = eiα · eiβ，全局相位不影响任何测量结果。

在哪里会用到？

• 第1课：概率幅 α,β ∈ ℂ，布洛赫球参数化中的 e^(iφ)

• 第2课：薛定谔方程中的 iℏ 和复波函数

• 第5课：Lindblad 方程中的复数退相位

2. 厄米算符与本征分解 / Hermitian Operators & Eigendecomposition

量子力学中，可观测量（能量、自旋、位置等）对应厄米算符。理解厄米算符是理解测量的关键。

定义 / Definition

算符 Ĥ 是厄米的，若 Ĥ = Ĥ† （等于自身的厄米共轭）

厄米算符有两个关键性质：

本征值都是实数：Ĥ|ψₙ⟩ = Eₙ|ψₙ⟩,　 Eₙ ∈ ℝ
不同本征值的本征态正交：⟨ψₘ|ψₙ⟩ = δₘₙ

谱分解 / Spectral Decomposition

Ĥ = Σ Eₙ |ψₙ⟩⟨ψₙ|

任何厄米算符都可以写成其本征态的"加权和"。|ψₙ⟩⟨ψₙ| 是本征态上的投影算符。

完备性关系（closure relation）：Σ |ψₙ⟩⟨ψₙ| = I（单位算符）

物理意义

厄米算符的本征值 = 测量可能得到的结果。

本征态 = 测量后系统会坍缩到的状态。

能量算符 Ĥ 的本征态 = 定态（stationary states）。

物理学中的厄米算符 / Common Hermitian Operators

• 能量（哈密顿量）：Ĥ = -ℏ²/(2m) ∇² + V(x)

• 动量：p̂ = -iℏ d/dx

• 角动量：L̂ = r × p̂

• 自旋：Ŝ = (ℏ/2) σ

在哪里会用到？

• 第5课：测量公设和 POVM 形式

• 第2课：能量本征态和薛定谔方程

• 第6课：BCS 哈密顿量

3. 时间演化算符 / Time Evolution Operator

含时薛定谔方程 iℏ ∂|ψ⟩/∂t = Ĥ|ψ⟩ 的解是什么？它给出时间演化算符。

形式解 / Formal Solution

|ψ(t)⟩ = e-iĤt/ℏ |ψ(0)⟩

其中 Û(t) = e-iĤt/ℏ 是时间演化算符（time evolution operator）。

Û(t) = Σ e-iEₙt/ℏ |ψₙ⟩⟨ψₙ|

物理直觉

时间演化算符 e-iĤt/ℏ 是一个旋转操作。

每个本征态 |ψₙ⟩ 以角频率 ωₙ = Eₙ/ℏ"旋转"（获得相位因子 e-iωₙt）。

不同能量的本征态获得不同相位 → 导致叠加态的"形状"随时间变化。

在能量本征基下 / In Energy Eigenbasis

|ψ(t)⟩ = Σ cₙ e-iEₙt/ℏ |ψₙ⟩,　 其中 cₙ = ⟨ψₙ|ψ(0)⟩

系数 cₙ 不随时间变化！只有相位因子旋转。可观测效应来自交叉项（干涉）。

在哪里会用到？

• 第7课：Transmon 门操作 = 演化

• 第5课：Rabi 振荡推导

• 第9课：量子门 = 受控时间演化

4. 量子谐振子 / Quantum Harmonic Oscillator

Transmon 的物理基础是量子谐振子。从弹簧到量子化 LC 电路，理解 QHO 是必经之路。

哈密顿量 / Hamiltonian

Ĥ = $\frac{p̂²}{2m} + \frac{1}{2}mω²x̂²$
Ĥ = ℏω (â†â + 1/2) = ℏω â†â + ℏω/2

其中 â = (mω/(2ℏ))1/2 (x̂ + i p̂/(mω)) 是湮灭算符。

能谱 / Energy Spectrum

Eₙ = ℏω (n + 1/2),　 n = 0, 1, 2, ...
â†â |n⟩ = √(n+1) |n+1⟩,　 â |n⟩ = √n |n-1⟩

能级等间距！零点能 ℏω/2 来自 [x̂, p̂] = iℏ 对易关系。

为什么 Transmon 会"丢掉 1/2"？

Transmon 的能级是 不等间距（非谐性）：Eₙ ≠ ℏω(n+1/2)

但如果定义零态 â† â（粒子-空穴对称），零点能的常数 ℏω/2 被吸收到零态能量的定义中。

Transmon 写作 â† â 而非 Ĥ = ℏω(â†â + 1/2)，是因为：零点能只是一个常数偏移，不影响动力学。

粒子数-相位不确定性

[â, â†] = 1,　 [φ̂, n̂] = i

粒子数 n̂ = â†â 和相位 φ̂ 是一对共轭变量。

n̂ 确定 → φ̂ 完全不确定（类似 [x̂, p̂] = iℏ）

在哪里会用到？

• 第7课：Transmon = 非谐 QHO

• 第8课：Transmon 谐振腔耦合

• 第6课：电路量子化

5. Rabi 振荡与旋转坐标系 / Rabi Oscillations & Rotating Frame

Rabi 旋进是量子二能级系统在周期驱动下的基本动力学，也是量子门操作的基础。

二能级系统的哈密顿量 / Two-Level System Hamiltonian

Ĥ = -ℏω₀ σ_z / 2 = -(ℏω₀/2) (|0⟩⟨0| - |1⟩⟨1|)

两个能级的能量差为 ℏω₀。

周期驱动 / Periodic Drive

Ĥ_drive = ℏΩ cos(ωt) σ_x / 2

以频率 ω 振荡的驱动场（如微波），耦合强度 ℏΩ。

Rabi 频率 / Rabi Frequency

Ω_R = √((ω - ω₀)² + Ω²) = √(Δ² + Ω²)

Δ = ω - ω₀ 是失谐（detuning），Ω 是 Rabi 频率（共振时 Ω_R = Ω）。

共振时（Δ=0），系统在 |0⟩ 和 |1⟩ 完全翻转。

旋转坐标系 / Rotating Frame

改变参考系到以驱动频率 ω 旋转的坐标系。

在新坐标系中，有效哈密顿量变为静磁场形式：

H_eff = ℏ(Δ σ_z + Ω σ_x) / 2

这就是布洛赫球中的旋转操作——量子门的物理图像。

脉冲与旋转 / Pulse & Rotation

U_pulse = exp(-i Ĥ_drive t / ℏ)

π/2 脉冲：t = π/(2Ω) → 从 |0⟩ 翻转到 (|0⟩ + |1⟩)/√2

π 脉冲：t = π/Ω → 从 |0⟩ 翻转到 |1⟩（非门操作）
