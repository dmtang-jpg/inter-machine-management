冯·诺依曼测量公设 / Von Neumann Measurement Postulate

投影测量 / Projective Measurement

测量可观测量 A = Σ aₙ |aₙ⟩⟨aₙ|，得到 aₙ 的概率：P(aₙ) = |⟨aₙ|ψ⟩|²

测量后系统坍缩到 |aₙ⟩：|ψ⟩ → |aₙ⟩（瞬时完成）

期望值 / Expectation Value

⟨A⟩ = ⟨ψ|A|ψ⟩ = Σ aₙ P(aₙ)

多次测量的统计平均

不确定性 / Uncertainty

ΔA = √(⟨A²⟩ − ⟨A⟩²)

仅当 |ψ⟩ 是 A 的本征态时为 0

测量坍缩物理图像 / Physical Picture of Collapse

这不是数学技巧，而是真实的物理过程。测量仪器与量子系统相互作用，破坏叠加态。

例：电子自旋 |ψ⟩ = (|↑⟩ + |↓⟩)/√2，测量 z 方向 → 50% 得到 ↑，50% 得到 ↓

POVM：广义测量 / General Measurement

定义 / Definition

{E₁, E₂, ..., Eₖ}，Eⱼ ≥ 0（正算子），Σ Eⱼ = I

概率：P(j) = Tr(Eⱼρ)，不需要是投影算子！

为什么需要 POVM？/ Why POVM?

• 描述联合测量后丢弃部分信息

• 描述不完全分辨的探测

• 描述系统+环境的复合测量

投影测量 PVM

• Eⱼ = |aⱼ⟩⟨aⱼ|

• EⱼEₖ = δⱼₖEⱼ

• 构成单位分解

POVM

• Eⱼ 只需正且和为单位

• EⱼEₖ 不一定正交

• PVM 是 POVM 的特例

典型例子：二能级系统非破坏性测量

E₁ = η|0⟩⟨0|,　 E₂ = η|1⟩⟨1|,　 E₃ = (1−η)I

η 是探测效率，E₃ 表示"未探测到"的结果。

T₁ 与 T₂ / Energy Relaxation & Dephasing

T₁：纵向弛豫时间

粒子数寿命

|1⟩ → |0⟩ 辐射跃迁

E = E₀ e^{-t/T₁}

T₂：横向退相干时间

相位相干时间

叠加态退相干为混合态

T₂ ≤ 2T₁

Bloch 方程（唯象）/ Phenomenological Bloch Equations

$\frac{d}{dt}\begin{pmatrix} \rho_{00} \\ \rho_{11} \\ \rho_{01} \end{pmatrix} = \begin{pmatrix} 0 & 1/T_1 & 0 \\ 0 & -1/T_1 & 0 \\ 0 & 0 & -1/T_2 \end{pmatrix} \begin{pmatrix} \rho_{00} \\ \rho_{11} \\ \rho_{01} \end{pmatrix}$

Ramsey 条纹实验 / Ramsey Fringe Experiment

π/2 脉冲 → 等待 τ → π/2 脉冲 → 测量

通过改变 τ 测量 T₂*（不均匀展宽），T₂ = (1/(2T₁) − 1/T₂*)^{-1}

林德布劳主方程 / Lindblad Master Equation

开放量子系统（系统+环境）动力学的最一般描述：

一般形式 / General Form

$\frac{dρ}{dt} = -i[Ĥ, ρ] + \sum_k γ_k \left( L_k ρ L_k^\dagger - \frac{1}{2}\{L_k^\dagger L_k, ρ\} \right)$

Lₖ 是 Lindblad 算子（跳跃算子），γₖ 是速率。

具体通道 / Concrete Channels

振幅阻尼（T₁）：L = |0⟩⟨1|,　 γ = 1/T₁
退相位（T₂）：L = σ_z,　 γ = 1/T_φ
T₂ = $\frac{1}{\frac{1}{2T_1} + \frac{1}{T_φ}}$

不动点 / Fixed Point

limt→∞ ρ(t) = ρss = |0⟩⟨0|（基态）

所有激发态最终弛豫到能量最低态（基态）。

量子芝诺效应 / Quantum Zeno Effect

"看沸腾的水不会开"

频繁测量抑制量子跃迁：若测量间隔 Δt ≪ T₁，系统来不及演化，保持在初态。

P(未跃迁) ≈ 1 − (Δt)²/τ² → 1（当 Δt → 0）

反芝诺效应 / Anti-Zeno Effect

频繁测量也可能加速跃迁（环境噪声辅助）。应用：量子纠错激发。

测量反作用 / Measurement Backaction

测量必然扰动系统：Δx Δp ≥ ℏ/2

量子非 demolition (QND) 测量：设计测量只获取信息而不扰动量子态。
