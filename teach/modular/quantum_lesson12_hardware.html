稀释制冷机 / Dilution Refrigerator

为什么需要极低温？

k_B T ≪ ℏω

热激发会破坏量子态。对于 Transmon：ℏω ~ 5 GHz → T ≪ 50 mK

P_{excited} = exp(-ℏω / k_B T)

当 T = 10 mK 时，P_{excited} ~ 10⁻¹⁰，热激发完全可以忽略。

³He/⁴He 稀释制冷原理

步骤1：³He 原子从 ⁴He 稀溶液进入浓溶液（吸热过程）
步骤2：制冷功率：Q̇ = 84 ṅ₃ T² [W]
步骤3：ṅ₃ 是 ³He 循环速率，典型值 ~100 μmol/s
T_{base} ≈ 7 mK（实际极限），典型工作温度 ~10-15 mK

制冷阶段

• 液氮预冷：77 K

• ⁴He 蒸发冷却：~1 K

• ³He/⁴He 稀释：~10 mK

• 降温时间：~12-24 小时

关键参数

• 制冷功率：~10 μW @ 100 mK

• ³He 价格：~¥1000/升

• 需要回收系统

• 振动隔离要求极高

读出链路 / Readout Chain

信噪比 (SNR) 推导

步骤1：信号功率 P_sig = (κ n̄)²，κ 是腔带宽，n̄ 是平均光子数
步骤2：噪声功率 P_noise = n̄_noise = n̄_th + n̄_amp
步骤3：SNR = (κ n̄)² / n̄_noise
SNR = \frac{(\kappa \bar{n})^2}{\bar{n}_{noise}} = \frac{\kappa^2 \bar{n}^2}{\bar{n}_{th} + \hbar \omega / (2 \eta)}

η 是放大器量子效率，n̄_th 是热噪声光子数。

读出保真度推导

步骤1：定义 P(0|0) 为准备 |0⟩ 时测量得到 0 的概率
步骤2：P(1|1) 为准备 |1⟩ 时测量得到 1 的概率
步骤3：保真度 F = (P(0|0) + P(1|1)) / 2
F = \frac{P(0|0) + P(1|1)}{2} = 1 - \frac{P_{error}}{2}

现代 Transmon 读出保真度 F > 99%，测量时间 ~100-500 ns。

量子纠错码 / Quantum Error Correction

[[n,k,d]] 码参数

n：物理量子比特数，k：逻辑量子比特数，d：码距

码距 d = 2t + 1 → 纠正 t 个任意错误

量子 Hamming 界：2^{n-k} ≥ Σ_{j=0}^{t} C(n,j) 3^j

Steane [[7,1,3]] 码

|0⟩_L = \frac{1}{\sqrt{8}} (|0000000⟩ + |1010101⟩ + |0110011⟩ + |1100110⟩ + |0001111⟩ + |1011010⟩ + |0111100⟩ + |1101001⟩)
|1⟩_L = \frac{1}{\sqrt{8}} (|1111111⟩ + |0101010⟩ + |1001100⟩ + |0011001⟩ + |1110000⟩ + |0100101⟩ + |1000011⟩ + |0010110⟩)

码距 d=3，纠正任意单量子比特错误。稳定子生成元：g₁=XIXIXIX, g₂=IXXIIXX, g₃=IIIXXXX, g₄=ZZZZZZZ, g₅=IZZIZZZ, g₆=IIIZZZZ

Surface Code

d=3：7×7 网格 = 49 物理比特，1 逻辑比特
d=5：13×13 网格 = 169 物理比特

仅需最近邻相互作用，易在超导电路实现。逻辑错误率：p_L ≈ (p/p_th)^{d/2}

错误阈值定理

如果物理门错误率 p < p_th ~ 1%，则通过级联编码可以指数降低逻辑错误率。

这是量子计算可行性的理论基础！

症候群提取 / Syndrome Extraction

稳定子测量

S_i = g_i ρ g_i^†

通过辅助量子比特测量稳定子生成元 g_i 的本征值（±1）。

错误诊断示例

假设 Steane 码中第 3 个量子比特发生 X 错误：

|ψ⟩ = X_3 |ψ_L⟩
g₁ = XIXIXIX → 与 X_3 对易 → 本征值 +1
g₂ = IXXIIXX → 与 X_3 反对易 → 本征值 -1
g₃ = IIIXXXX → 与 X_3 反对易 → 本征值 -1
症候群 (+1, -1, -1) → 唯一确定错误位置在第 3 个量子比特

关键约束

症候群只告诉错误类型和位置，不告诉逻辑态信息！

这是量子纠错的核心：获取错误信息而不坍缩逻辑态。

量子体积与基准测试 / Quantum Volume & Benchmarking

量子体积 (QV) 定义

QV = 2^k, \quad k = \max\{n | \text{随机电路通过随机基准测试}\}
步骤1：构建 n×n 随机酉电路（随机单比特门 + 随机双比特门）
步骤2：运行电路，测量输出分布 p_{exp}
步骤3：计算理想输出分布 p_{ideal}
步骤4：计算交叉熵：H(p_{ideal}, p_{exp}) > 2/3 → 通过

交叉熵基准

F_{XEB} = 2^n \langle p_{ideal}(x) \cdot p_{exp}(x) \rangle - 1

F_{XEB} = 1 → 完美，F_{XEB} = 0 → 完全随机
