含时薛定谔方程 / Time-Dependent Schrödinger Equation

基本形式 / Fundamental Form

iℏ $\frac{\partial}{\partial t}$ |ψ(t)⟩ = Ĥ |ψ(t)⟩

i 是虚数单位，ℏ = h/(2π) 是约化普朗克常数，Ĥ 是哈密顿算符。

哈密顿算符 / Hamiltonian

Ĥ = -ℏ²/(2m) ∇² + V(r)

动能项 + 势能项

波函数 / Wave Function

|ψ(t)⟩ 是 Hilbert 空间中的矢量

描述量子系统的完整状态

物理意义 / Physical Meaning

薛定谔方程是量子力学的"牛顿第二定律"——给定初始状态 |ψ(0)⟩，可以计算未来任意时刻的状态。

它是确定性的！随机性只在测量时出现。

一维无限深势阱 / 1D Infinite Square Well

最简单的量子力学问题：电子被限制在 0 到 L 的区域内，势能 V=0；区域外 V=∞。

定态薛定谔方程 / Time-Independent SE

-$\frac{ℏ^2}{2m} \frac{d^2 \psi_n(x)}{dx^2} = E_n \psi_n(x)$

边界条件：ψ(0) = ψ(L) = 0

解析解 / Analytical Solution

ψn(x) = $\sqrt{\frac{2}{L}} \sin\left(\frac{n\pi x}{L}\right)$,　 En = $\frac{n^2 \pi^2 ℏ^2}{2mL^2}$,　 n = 1,2,3,...

n 是量子数，E_n 是能量本征值。能量是离散的（量子化）！

前三个能级的波函数 ψₙ(x) 和概率密度 |ψₙ(x)|²

能量量子化 / Energy Quantization

驻波类比 / Standing Wave Analogy

吉他弦两端固定，只能以特定频率振动：f_n = nv/(2L)

电子波函数在有限空间内，也只允许特定频率的驻波模式存在。

这就是能量量子化的起源：边界条件 → 驻波条件 → 离散谱

零点能 / Zero-Point Energy

最低能量 E₁ = π²ℏ²/(2mL²) ≠ 0

海森堡不确定性原理：位置越确定，动量越不确定

能级间距 / Energy Spacing

ΔE = E_{n+1} - E_n = (2n+1)π²ℏ²/(2mL²)

n 越大，间距越大（与 n 成正比）

思考题：

若电子被限制在 L=1nm 的区域内，基态能量约为多少？（m_e = 9.1×10⁻³¹ kg, ℏ = 1.05×10⁻³⁴ J·s）

提示：E₁ = π²ℏ²/(2mL²) ≈ 6×10⁻²⁰ J ≈ 0.4 eV

自旋½系统 / Spin-½ System

电子的内禀角动量（自旋）是量子化的，只能取两个值：

自旋算符 / Spin Operators

Ŝ² |s,m⟩ = ℏ² s(s+1) |s,m⟩,　 Ŝ_z |s,m⟩ = ℏm |s,m⟩

对于电子：s = 1/2，m = ±1/2

|↑⟩ = |+½⟩,　 |↓⟩ = |-½⟩

泡利矩阵 / Pauli Matrices

σ_x = $\begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$,　 σ_y = $\begin{pmatrix} 0 & -i \\ i & 0 \end{pmatrix}$,　 σ_z = $\begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}$

Ŝ_i = (ℏ/2) σ_i，满足对易关系 [σ_i, σ_j] = 2iε_{ijk}σ_k

自旋向上 Spin up
|↑⟩ = $\begin{pmatrix}1\\0\end{pmatrix}$
自旋向下 Spin down
|↓⟩ = $\begin{pmatrix}0\\1\end{pmatrix}$

测量与坍缩 / Measurement & Collapse

经典世界：抛硬币

• 硬币在空中旋转

• 结果已确定（隐变量）

• 我们只是不知道

• 接住 → 看到结果

量子世界：电子自旋

• 电子同时是↑和↓

• 结果真的未确定

• 贝尔不等式已证实

• 测量 → 迫使选择

测量公设 / Measurement Postulate

测量可观测量 A，得到本征值 a_n 的概率 = |⟨a_n|ψ⟩|²

测量后，系统坍缩到对应的本征态 |a_n⟩。这就是波恩定则（Born rule）。

量子比特的物理载体 / Physical Carriers of Qubits

电子的量子特性如何用来编码 0 和 1？

电子自旋

↑ 自旋向上 → |0⟩

↓ 自旋向下 → |1⟩

⚠️ 电子没有大小，"自旋"是内禀属性

原子能级

E₀ 基态 → |0⟩

E₁ 激发态 → |1⟩

能量离散 = 楼梯 vs 斜坡

为什么能量是离散的？

就像吉他弦只能以特定频率振动（基频、2倍频、3倍频……）
