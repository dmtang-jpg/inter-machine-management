超导现象 / Superconductivity Phenomenon

零电阻 / Zero Resistance

• 低于临界温度 Tc，直流电阻严格为0

• 持续电流实验证实：无能量损耗

• 与理想导体不同（后者仅无电阻）

完全抗磁性 / Perfect Diamagnetism (Meissner)

• 超导体内部 B = 0

• 磁场被排出体外

• 不是零电阻的推论！是独立性质

关键澄清：超导 ≠ 理想导体

理想导体：电阻为零，但内部磁场保持不变（法拉第定律）。

超导体：零电阻 + 主动排出磁场（Meissner效应）。这是热力学相变！

临界参数 / Critical Parameters

T_c (临界温度),　 H_c (临界磁场),　 J_c (临界电流密度)

三者都是阈值：超过任何一个，超导态被破坏。

BCS 理论 / Bardeen-Cooper-Schrieffer Theory

库珀对 / Cooper Pair

• 两个电子通过晶格振动（声子）间接吸引

• 总自旋 S = 0（自旋单态）

• 总动量 q ≈ 0（动量相反）

• 束缚能 ~ meV 量级

BCS 基态 / BCS Ground State

• 所有库珀对凝聚到同一量子态

• 宏观波函数 Ψ = |Ψ|e^{iφ}

• 相位 φ 宏观相干

→ 零电阻的起源

BCS 哈密顿量 / BCS Hamiltonian

Ĥ = Σkσ εk c†kσckσ + Σk,k' Vkk' c†k↑c†-k↓ck'↓c-k'↑

c†kσ 是动量 k、自旋 σ 的电子产生算符。最后一项是电子-电子散射（声子媒介）。

能隙方程 / Gap Equation

Δ(T) = Δ(0) tanh($\frac{π k_B T_c}{Δ(0)} \sqrt{\frac{8}{7ζ(3)}(\frac{T_c}{T} - 1)}$)

在 T = 0 时，Δ(0) ≈ 1.76 kBTc（弱耦合极限）。

London 方程 / London Equations

唯象描述超导体电磁性质的两个方程：

第一 London 方程 / First London Equation

$\frac{\partial \mathbf{J}_s}{\partial t} = \frac{n_s e^2}{m_e} \mathbf{E}$

超流电流变化率 ∝ 电场（而不是 J ∝ E，即电阻性）。

第二 London 方程 / Second London Equation

$\nabla \times \mathbf{J}_s = -\frac{n_s e^2}{m_e c} \mathbf{B}$

结合麦克斯韦方程，给出指数衰减的磁场：

$\mathbf{B}(x) = \mathbf{B}_0 e^{-x/\lambda_L}$

London 穿透深度 / London Penetration Depth

$\lambda_L = \sqrt{\frac{m_e}{\mu_0 n_s e^2}}$

n_s 是超流电子密度。λ_L ~ 50-500 nm（典型值）。

库仑阻塞 / Coulomb Blockade

小电容结对中，单电子充电能阻止后续电子隧穿：

充电能 / Charging Energy

$E_c = \frac{e^2}{2C_\Sigma}$

C_Σ 是结的总电容。当结尺寸 < 100 nm，E_c 可以与热能 k_BT 相比拟。

阻塞条件 / Blockade Condition

$eV_{bias} < E_c$ 且 $k_B T \ll E_c$

外电压提供的能量 < 充电能 → 电子无法隧穿 → 电流被抑制。

单电子晶体管 / Single-Electron Transistor (SET)

• 栅极电压控制岛电位

• 库仑振荡：电流随 V_g 周期变化

• 周期 ΔV_g = e/C_g

应用

• 电荷传感器（极高灵敏度）

• 电流标准（单电子泵）

• 量子点量子比特

超导量子比特分类 / Types of Superconducting Qubits

类型哈密顿量量子数
电荷量子比特 (Charge/Coulomb box) Ĥ = 4E_C(n̂ - n_g)² - E_J cos(φ̂) 电荷数 n̂
磁通量子比特 (Flux qubit) Ĥ = Q²/(2C) - E_J cos(φ̂) + (Φ_ext - Φ₀/2)²/(2L) 磁通 φ
Transmon Ĥ ≈ 4E_C n̂² + E_J(1 - φ̂²/2) 电荷数（大E_J/E_C极限）

关键参数比 / Key Parameter Ratio

$E_J/E_C$ 决定量子比特性质

E_J/E_C ≪ 1：电荷量子比特（电荷噪声敏感）

E_J/E_C ≫ 1：Transmon（磁通噪声敏感，但对电荷噪声不敏感）

为什么 E_J/E_C 很重要？

量子比特极化取决于参数比。E_J/E_C ~ 50-80 是 Transmon 的优化值。
