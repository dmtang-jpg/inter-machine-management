量子纠缠 vs 经典关联 / Entanglement vs Classical Correlation

经典关联（手套盒子）

• 分开时已确定

• 只是我们不知道

• 打开一盒→知道另一盒

• 信息已存在

量子纠缠

• 测量前真的未确定

• 贝尔不等式实验证实

• 测量A→B立即确定

• 信息在测量时产生

关键区分

经典关联 = 结果在分开时已确定，只是你不知道。

量子纠缠 = 结果在测量前真的未确定。贝尔不等式实验已反复证实。

四个贝尔态 / The Four Bell States

两量子比特系统的最大纠缠态（贝尔态）是 ℂ⁴ 空间的一组正交归一基：

贝尔基 / Bell Basis

|Φ⁺⟩
(|00⟩ + |11⟩)/√2
|Φ⁻⟩
(|00⟩ − |11⟩)/√2
|Ψ⁺⟩
(|01⟩ + |10⟩)/√2
|Ψ⁻⟩
(|01⟩ − |10⟩)/√2

纠缠性质 / Entanglement Properties

|Φ⁺⟩ = (|↑↑⟩ + |↓↓⟩)/√2

• 完美关联：测量 A 得到 |0⟩，B 必定是 |0⟩；测量 A 得到 |1⟩，B 必定是 |1⟩

• 不可分离：不存在单量子比特态 |α⟩, |β⟩ 使得 |Φ⁺⟩ = |α⟩ ⊗ |β⟩

• 最大纠缠：约化密度矩阵 ρ_A = I/2（最大混合态）

EPR 佯谬 / Einstein-Podolsky-Rosen Paradox

EPR 论证 (1935)

1. 两个粒子相互作用后分离，处于纠缠态（如 |Φ⁺⟩）

2. 测量粒子1的位置，可以推断粒子2的位置

3. 测量粒子1的动量，可以推断粒子2的动量

4. 但粒子1的位置和动量不可能同时确定（不确定性原理）

5. 所以粒子2的位置和动量必须同时是"物理实在"的

6. 但量子力学说它们不是同时确定的

7. 结论：量子力学是不完备的（存在隐藏变量）

爱因斯坦的立场

• 存在隐藏变量

• 量子力学不完备

• "上帝不掷骰子"

玻尔的回应

• 不存在隐藏变量

• 测量前真的未确定

• 量子力学是完备的

CHSH 不等式 / CHSH Inequality

贝尔不等式的一种形式（CHSH, 1969），可以实验检验：

CHSH 关联函数 / CHSH Correlation Function

S = E(a,b) − E(a,b') + E(a',b) + E(a',b')

其中 E(a,b) = P(相同) − P(不同)，是测量方向 a 和 b 的关联函数。

隐变量理论的界限 / Hidden Variable Bound

|S| ≤ 2

任何局域隐变量理论都满足这个不等式！

量子力学的预测 / Quantum Mechanical Prediction

|SQM| = 2√2 ≈ 2.828 > 2

对于 |Ψ⁻⟩ 态，选择特定角度：a=0°, a'=45°, b=22.5°, b'=67.5°

测量对角度差E 值
(a, b)22.5°−1/√2
(a, b')67.5°1/√2
(a', b)22.5°−1/√2
(a', b')22.5°−1/√2
S =−2√2

密度矩阵 / Density Matrix

对于混合态（统计混合），需要用密度矩阵描述：

纯态 vs 混合态 / Pure State vs Mixed State

纯态：ρ = |ψ⟩⟨ψ|,　 Tr(ρ²) = 1
混合态：ρ = Σ pᵢ |ψᵢ⟩⟨ψᵢ|,　 Tr(ρ²) < 1

约化密度矩阵 / Reduced Density Matrix

ρA = TrB(ρAB)

对于 |Φ⁺⟩ = (|00⟩ + |11⟩)/√2：

ρA = TrB(|Φ⁺⟩⟨Φ⁺|) = (⟨0|0⟩⟨0|0⟩ + ⟨1|1⟩⟨1|1⟩)/2 = I/2

约化密度矩阵是最大混合态 → 说明子系统 A 与 B 最大纠缠！

纠缠判据 / Entanglement Criterion

部分转置判据（Peres-Horodecki）：

若 ρT_A 有负本征值 → 纠缠

纠缠熵 / Entanglement Entropy

S(ρA) = −Tr(ρA log ρA)

对于 |Φ⁺⟩：S = log 2 = 1

贝尔不等式实验 / Bell Inequality Experiments

实验证实

• 阿斯佩实验 (1982)：首次验证

• 所有实验都支持量子力学

• 纠缠态的结果真的未确定

漏洞关闭

• 局域性漏洞 (2015)

• 检测效率漏洞

• 自由意志漏洞

实验意义

贝尔不等式实验排除了局部隐变量理论。

量子力学是非局域的（nonlocal）——纠缠粒子间的关联不受距离限制。

为什么 n 个量子比特 = 2ⁿ 个态

类比：走迷宫

经典计算机像一个人走迷宫——一次只能走一条路。

量子计算机像 2^N 个分身同时探索每条岔路。

严格推导 / Rigorous Derivation

|ψ⟩ = Σx∈{0,1}n cx |x⟩,　 Σ |cx|² = 1

n 个量子比特的一般态是 2ⁿ 个基态的线性叠加。

存储所有概率幅需要 2ⁿ 个复数（忽略归一化）。

经典存储

n 比特 → n 个经典位

只能存储 1 个 n 位二进制串

量子存储

n 量子比特 → 2ⁿ 个复数

可以同时处于 2ⁿ 个态的叠加
